# 基于轻量化大语言模型的游戏角色 AI 对话系统

本项目用于实现毕设《基于轻量化大语言模型的游戏角色AI对话系统设计与实现》。

系统目标是让玩家通过文本聊天界面，与具有稳定人格、知识边界和剧情感知能力的游戏角色进行多轮自由对话。整体方案以轻量化本地模型为核心，结合 RAG、权限过滤、动态记忆、安全约束与状态迁移机制，构建可离线运行、可评估、可扩展的角色 AI 对话原型。

## 研究目标

- 构建面向游戏角色的结构化知识体系，覆盖角色设定、世界观、剧情与关系网络。
- 基于 RAG 检索相关知识，并结合权限控制限制角色可访问的信息范围。
- 通过提示工程、上下文管理和记忆机制，提升角色一致性，降低 OOC 与幻觉。
- 使用轻量化大模型完成本地推理，为后续 Unity/UE 集成提供后端服务。
- 建立测试界面与评估指标，对一致性、时延、资源消耗和安全性进行验证。

## 当前仓库状态

当前仓库已经具备以下基础资源：

- `data/raw/`：原始知识文本，按角色、主线、支线、世界观分层组织。
- `tests/`：包含若干面向检索排序、场景清洗、向量化实验的测试或验证脚本。
- `src/`：预留了核心模块文件，但大部分文件仍待实现。

这意味着项目已经完成了数据侧准备和部分行为预期定义，下一阶段重点是把系统模块真正实现出来，并形成统一工程结构。

## 技术路线

- 生成模型：`Qwen3:8B`
- 本地推理部署：`Ollama`
- 嵌入模型：`BAAI/bge-small-zh-v1.5`
- 向量索引：`FAISS`
- 后端框架：`FastAPI`
- 测试与演示界面：`Gradio`
- 游戏引擎接入：`Unity/UE` 通过 HTTP 调用后端接口

## 系统模块

### 1. 角色知识图谱与动态记忆

- 存储角色身份、性格、口头禅、关系、经历、所属地区与势力。
- 拆分短期记忆、长期记忆、剧情状态记忆。
- 支持随版本更新和玩家进度推进进行增量写入。

### 2. 提示工程与上下文管理

- 将角色设定、可用知识、剧情状态、历史对话与玩家输入拼装为系统提示。
- 增加角色一致性约束与回答边界约束。
- 对场景文本进行清洗和摘要，避免噪声污染上下文。

### 3. RAG 与权限过滤

- 对世界观、主支线剧情、角色资料进行分块和向量化。
- 基于角色权限规则过滤候选知识。
- 在检索结果中兼顾语义相关性与剧情时间顺序。

### 4. 本地模型推理

- 通过 Ollama 调用轻量化模型。
- 后续可加入角色专属对话数据微调或指令模板强化。
- 平衡响应质量、延迟和显存占用。

### 5. 安全过滤

- 检测恶意诱导、敏感内容、越权询问和无关输入。
- 输出拒绝、规避或引导式回复。

### 6. 对话状态管理与版本迁移

- 记录会话历史、角色状态、玩家进度、知识版本号。
- 当知识库更新时，对旧会话进行兼容和迁移。

### 7. 评估与可视化测试

- 提供 Gradio 测试入口。
- 评估角色一致性、剧情准确性、响应时延、资源占用和鲁棒性。

## 推荐目录规划

推荐后续按如下方式扩展：

```text
src/
  chat.py                       # 对话主流程编排
  retriever.py                  # 检索与权限过滤
  build_metadata.py             # 文本元数据构建
  build_vector_db_with_metadata.py
  extract_role_info.py          # 从角色资料提取基础信息
  generate_role_permissions.py  # 生成角色权限规则
  memory.py                     # 动态记忆管理
  prompt_builder.py             # 提示词拼装
  safety.py                     # 输入安全过滤
  state_manager.py              # 会话状态与版本迁移
  api.py                        # FastAPI 服务入口

data/
  raw/                          # 原始文本
  processed/                    # 清洗、切分后的结构化结果
  vector_db/                    # FAISS 索引与元数据
  permissions/                  # 角色权限配置
  memory/                       # 对话记忆快照
  eval/                         # 测试集与评估结果
```

## 开发顺序建议

1. 完成元数据构建、文本切块和向量库生成。
2. 完成角色信息抽取与权限规则生成。
3. 实现带权限过滤的检索器。
4. 实现提示构建与基础对话主流程。
5. 接入 Ollama 和本地模型推理。
6. 增加记忆、安全过滤与状态管理。
7. 提供 FastAPI 接口、Gradio 页面和 Unity 演示接入。
