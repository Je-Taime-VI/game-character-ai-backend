# 编辑器补充需求（2026-04-17）

## 1. 块类型命名调整

新的用户可见块类型统一为：

- 场景&人物
- 旁白
- 台词
- 分支选项
- 剧情梗概
- 文本标题
- 文本正文
- 解析

对应关系建议：

- 场景&人物 -> `scene_cast`
- 旁白 -> `narration`
- 台词 -> `line`
- 分支选项 -> `branch`
- 剧情梗概 -> `summary`
- 文本标题 -> `text_title`
- 文本正文 -> `text_body`
- 解析 -> `analysis`

兼容映射建议：

- 原“旁白·小”迁移为“旁白”
- 原“旁白·大”迁移为“文本标题”
- 原“旁白·补充”迁移为“解析”
- “文本正文”的字号、颜色、间距与“旁白”保持一致

## 2. 编辑交互调整

新编辑器不再保留右下角大文本编辑区。

改为：

- 所有块文本直接在中间预览区内编辑
- 点击块后进入就地编辑状态
- 点击注释词仍可打开注释详情弹窗
- 右侧栏改为“块操作与扩展操作区”，保留：
  - 字体倾斜
  - 为分支选项新增选项
  - 为分支选项新增新后续块
  - 注释引用
  - 注释查询
  - 新建注释

## 3. 右侧栏建议定位

右侧栏不再负责承载正文输入，而是负责：

- 新增块
- 当前选中块的结构化操作
- 当前选中块的注释操作
- 分支块的选项管理
- 分支选项的后续块新增入口

## 4. 布局与视觉参考

可继续沿用旧编辑器的总体视觉方向：

- 深蓝背景与卡片式分栏
- 左侧文档信息与块操作
- 中间大预览区
- 右侧新增块与扩展操作
- 模态弹窗风格保留圆角深色卡片

但交互重心要从“右侧编辑文本”转为“中间预览区直接编辑”。
